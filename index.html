    Change the item list with a CSV file

    Download the list, edit it in Excel, Google Sheets or WPS, then load it back. You can replace the whole list or only add and update items.

    Step by step guide
    1. Press Download current list (CSV). The file sri-crackers-items.csv is saved in your Downloads folder.
    2. Open it in Excel, Google Sheets or WPS Office.
    3. Change prices, add a row for each new item, and delete rows for items you no longer sell. Do not change the first row (the column names).
    4. Columns: Item No, Product Name, Tamil Name, Category, Category Tamil, Price, Per, No Discount. Write Yes under No Discount for items that must not get a discount. Leave Item No empty to get a new number.
    5. Save as CSV UTF-8 (Excel: File, Save As, choose "CSV UTF-8 (Comma delimited)"). Do not save as .xlsx, and do not use plain "CSV", or the Tamil letters will break.
    6. Come back here and press Choose CSV file, then pick your file.
    7. Check the preview: number of items, skipped rows and the first rows.
    8. Choose Replace the whole list to remove all old items and use only the new file, or Add and update to keep the old items.
    9. Press the green button. Replacing asks you to press it a second time.
    10. Made a mistake? Press Undo last import. Bills you already made never change, they keep the items and prices they were made with.

    Connect more computers and phones

    All devices share one set of items, bills, customers and stock through a small sync server (see SYNC-GUIDE.txt). It works on the shop WiFi / LAN, or over the internet if the server is hosted online. Each device keeps working offline and syncs when it can reach the server.

    Backup

    Items, shop details and saved bills are stored on this device. Download a backup file to move them to another phone or computer.
